# ПОЛЕ ОПЫТОВ · FIELD·5

Исследовательский проект: **пять радикально разных экспериментальных сайтов** о будущем веба,
лаборатория микро-демо и интерактивный отчёт — в одном приложении на единственном маршруте `/`.

> «Что случается с сайтом, когда перестаёшь считать его страницей?»

Меня зовут Савелий Гарбес. Мне было интересно проверить, какими ещё бывают веб-сайты, если
отказаться от привычной метафоры «страницы с контентом». Я разобрал современный иммерсивный
веб (канон Awwwards за десять лет, статус свежих API браузеров), выбрал пять направлений,
которые почти не пересекаются ни по визуальному языку, ни по интерактиву, ни по технической
базе — и реализовал каждое как полноценную сцену. Вместе с лабораторией прототипов и
интерактивным отчётом это «поле опытов»: место, где приёмы отрабатывались на приборах,
попадали в эксперименты и сравнивались по осям.

## Запуск

```bash
bun install
cp .env.example .env      # DATABASE_URL для SQLite
bun run db:push           # применить prisma-схему (создаст db/custom.db)
bun run dev               # http://localhost:3000
```

Пользовательский маршрут один — `/`. Все сцены переключаются хеш-роутером внутри страницы:

| Хеш | Сцена |
|---|---|
| `#/` | Хаб-витрина (старт) |
| `#/monolith` | ЭКСП. 01 «МОНОЛИТ» |
| `#/synthesis` | ЭКСП. 02 «СИНТЕЗ» |
| `#/archive` | ЭКСП. 03 «АРХИВ НЕВОЗМОЖНОГО» |
| `#/textfield` | ЭКСП. 04 «ТЕКСТОВОЕ ПОЛЕ» |
| `#/organism` | ЭКСП. 05 «ОРГАНИЗМ» |
| `#/lab` | Лаборатория (8 живых демо) |
| `#/report` | Интерактивный исследовательский отчёт |

Проверки: `bun run lint` (ESLint), `bunx tsc --noEmit` (типы).

## Пять экспериментов

### 01 «МОНОЛИТ» — веб как цифровая скульптура
Бесконечная процедурная пустошь из чёрных монолитов в тлеющем тумане, отрисованная **одним
фрагментным шейдером на чистом WebGL2**: SDF + доменное повторение, мягкие тени, туман со
«сходимостью к углям», ACES-тонмаппинг, дизеринг, динамическое разрешение (0.5–1.0 по времени
кадра). Скролл — путешествие вглубь, курсор — парящий светоч, 5 сигил с захватом по близости,
финал — «восхождение». Без единой библиотеки.

### 02 «СИНТЕЗ» — сайт как музыкальный инструмент
Звуковой сад **без единого аудиофайла**: 4 типа семян (дрон/щипок/хор/удар) — это голоса
синтеза (осцилляторы, фильтры, LFO, евклидовы ритмы, пентатоника ля-минор, 92 BPM, цикл из 4
аккордов). Реверб — свёртка с **процедурно сгенерированным impulse response**. Позиция растения
в саду = стереопанорама и посыл в реверб: аранжировка выполняется посадкой. FFT мастер-шины
питает фоновый WebGL-шейдер и пульсацию растений.

### 03 «АРХИВ НЕВОЗМОЖНОГО» — сайт как место
3D-галерея на **three.js r186**: девять процедурных скульптур (лента Клейна, гироид-сфера,
мёбиусов собор, суперформула, торус-узел, L-дерево, город Вороного, шум-метеорит, решётка
гиперболоида) в тёплом тумане. Уникальная навигация — **«гравитация внимания»**: камера
дрейфует сама и тянется к тому, на чём задерживается курсор; клик — полёт и орбита; у каждого
экспоната — карточка с реальными параметрами генератора и «пересев» семени на глазах.

### 04 «ТЕКСТОВОЕ ПОЛЕ» — текст как физическая материя
Кинетическая типографика с **собственным физическим движком** (импульсный солвер AABB-глифов,
верлет-связи, сон-состояния, глиф-атлас по measureText). Четыре акта: падение и куча, ткань
из предложения (тянется и рвётся), ветер от курсора, и «ваш голос» — собственный текст
попадает в ту же физику. Швейцарская бруталистика: бумага, чернила, сигнальный красный.

### 05 «ОРГАНИЗМ» — интерфейс, определяемый действиями пользователей
Одно коллективное существо на всех посетителей, **живущее в базе** (Prisma/SQLite):
движение и присутствие дают «энергию внимания», за 40 — прививка ветви, за 10 — пульс-волна.
Все мутации всех посетителей пишутся в общую историю; организм растёт из неё
**детерминированно** (seeded RNG по id мутации), поколения сменяются каждые 12 прививок,
интерфейс «взрослеет». Перезагрузка страницы — организм помнит.

## Лаборатория и библиотека

`#/lab` — 8 приборных панелей с живыми параметрами: поле потока, curl-шум, SDF-площадка
(raymarch с тумблером качества), дизеринг и палитры (Bayer 4×4), обратная связь (трейлы),
текст→частицы, L-сад, верлет-канат. Переиспользуемые модули: `src/lib/lab/`
(`types.ts` — контракт демо, `useDemoLoop.ts` — RAF-lifecycle, `math.ts` — шум/RNG/изинги,
`glkit.ts` — минимальный WebGL2-набор). Подробнее: `docs/LAB.md`.

## Отчёт

`#/report` — интерактивный исследовательский отчёт: витрина пяти экспериментов, сравнительный
радар и матрица, выводы разведки с источниками, находки и честные ограничения, живая телеметрия.

## Структура

```
src/
  app/
    page.tsx              # единственный маршрут: хеш-роутер + ленивые сцены
    layout.tsx            # шрифты (Onest/JetBrains/Cormorant/Unbounded, кириллица)
    api/telemetry/        # POST/GET телеметрия визитов
    api/organism/         # GET/POST организм (мутации, энергия, поколения)
  lib/
    router.ts             # useHashRoute
    db.ts, rate-limit.ts  # prisma-клиент, скользящий rate-limit
    lab/                  # библиотека лаборатории (переиспользуемая)
  sites/
    manifest.ts           # метаданные 5 экспериментов
    hub/                  # витрина (фон-поле пыли, живые превью)
    monolith/ synthesis/ archive/ textfield/ organism/
    lab/ report/
prisma/schema.prisma      # Organism / Mutation / Visit
research/                 # разведка: references, tech-notes, summary, план
docs/                     # ARCHITECTURE, LAB, QA-FINDINGS
```

## Технологии

Next.js 16 (App Router) · React 19 · TypeScript strict · Tailwind CSS 4 · three.js r186 ·
WebGL2/GLSL · Web Audio API · Canvas 2D · Prisma 6 + SQLite · framer-motion.

## Известные ограничения (честно)

- FPS GPU-тяжёлых сцен («МОНОЛИТ») в headless-проверке без GPU (SwiftShader) — единицы кадров;
  целевая платформа — современные браузеры с аппаратным ускорением (динамическое разрешение
  встроено). Полный список: `docs/QA-FINDINGS.md`.
- Звук «СИНТЕЗА» проверен структурно (граф без ошибок, анализатор питает визуализацию);
  headless-браузер не воспроизводит аудио — послушайте сами.
- WebGPU сознательно не использован: не Baseline (Firefox/Safari — за флагами), см. `research/tech-notes.md`.
