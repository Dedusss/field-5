# План пяти экспериментов — «ПОЛЕ ОПЫТОВ» / FIELD·5

План зафиксировал после разведки (см. research/references.md, research/tech-notes.md,
research/summary.md). Ключевые решения разведки: ядро рендера — WebGL2 (WebGPU ещё не Baseline:
Firefox/Safari за флагами), three.js 0.186 для 3D-сцены, весь звук — синтез Web Audio без ассетов
(контекст только по user gesture), физика текста — собственный движок (Matter.js изучен как
ориентир, но собственная реализация — часть эксперимента), персистентность — Prisma/SQLite
через API-роуты (паттерн «whispers» Bruno Simon: лимиты, деградация при офлайне).

## ЭКСП. 01 — «МОНОЛИТ» (slug: monolith)
- **Измерение веба:** сайт как цифровая скульптура / шейдерный рендеринг.
- **Концепция:** бесконечная процедурная пустошь из чёрных монолитов в тлеющем тумане.
  Скролл — это движение вглубь (путешествие), курсор — парящий уголь-светоч, освещающий
  ближайшие грани. В монолитах спрятаны 5 светящихся сигил; приближение активирует захват —
  палитра мира сдвигается. Все 5 — «восхождение»: туман поднимается, мир раскрывается.
- **Технологии:** чистый WebGL2 (без библиотек), один fullscreen фрагментный шейдер:
  raymarching SDF (box + domain repetition по Z, вариации высот hash/fbm), мягкие тени,
  температурный туман со сходимостью к свету курсора, ACES-тонмаппинг, дизеринг от бандинга,
  динамическое разрешение по времени кадра (0.5–1.0), DPR-кап 2.
- **Уникальная механика:** свет следует за курсором в 3D (перенос 2D-указателя в позицию
  света перед камерой) + захват сигил по близости камеры.
- **Критерий успеха:** непрерывное путешествие скроллом без подлагиваний (60 fps на средней
  GPU за счёт dynamic res), 5 сигил находятся, палитровые сдвиги читаются, полный teardown.

## ЭКСП. 02 — «СИНТЕЗ» (slug: synthesis)
- **Измерение веба:** аудиореактивное пространство, сайт как музыкальный инструмент.
- **Концепция:** сад звуков. Клик по земле сажает одно из 4 семян (Дрон / Щипок / Хор / Удар),
  из него вырастает биолюминесцентное растение, которое играет свою партию в общем
  полиритме (92 BPM, пентатоника, гармонический цикл). Вся сцена дышит от FFT мастер-шины:
  бас — пульс земли, верха — мерцание спор. Позиция растения = стереопанорама и «влажность»
  (уход в реверб).
- **Технологии:** Web Audio граф собственной сборки (осцилляторы/фильтры/LFO, синтетический
  impulse response для ConvolverNode, задержки), AnalyserNode → uniform-ы фонового
  WebGL-шейдера; растения и споры — Canvas 2D (рекурсивные L-ветви, пульсирующие по своим
  полосам FFT). Ноль аудио-ассетов.
- **Уникальная механика:** садоводство как секвенсор — расстановка растений по полю
  и есть аранжировка (позиция = панорама/реверб).
- **Критерий успеха:** вход по жесту (autoplay policy), посаженные растения слышим и видим,
  FFT видимо управляет графикой, музыкальность (грид, пентатоника), чистое выключение звука
  при выходе.

## ЭКСП. 03 — «АРХИВ НЕВОЗМОЖНОГО» (slug: archive)
- **Измерение веба:** 3D-пространство и нетривиальная навигация, сайт как место.
- **Концепция:** парящая галерея из 9 процедурных скульптур «невозможных вещей» в тёплом
  тумане (единственный светлый проект сетки). Каждая скульптура — документированный вид:
  алгоритм, параметры, семя. Клик — полёт камеры к экспонату, вокруг него орбита;
  двойной клик — освобождение в дрейф.
- **Технологии:** three.js r186: процедурная геометрия (Klein-лента, gyroid-оболочка,
  Möbius-собор, суперформула-цветок, торус-узел, L-система, Вороной-город, шум-метеорит,
  гиперболоидная решётка), ACESFilmic, туман, кастомные вершинные смещения, где уместно;
  полный dispose при unmount.
- **Уникальная механика:** «гравитация внимания» — камера мягко ускоряется к тому, на чём
  задержался курсор; навигация — дрейф у краёв экрана; у каждого экспоната кнопка
  «перебросить семя» — скульптура перегенерируется на глазах.
- **Критерий успеха:** 9 визуально разных скульптур, полёты камеры без рывков, карточки
  экспонатов с реальными параметрами генератора, 60 fps на средней GPU.

## ЭКСП. 04 — «ТЕКСТОВОЕ ПОЛЕ» (slug: textfield)
- **Измерение веба:** кинетическая типографика, текст как физическая материя.
- **Концепция:** манифест о будущем текста, где буквы — тела с массой. Четыре акта:
  «ПАДЕНИЕ» (заголовок осыпается и складывается в кучу), «ТКАНЬ» (предложение — верлет-ткань
  из глифов, её можно тянуть и рвать), «ВЕТЕР» (абзац пружинит к дому, курсор — ветер и
  турбулентность), «ВАШ ГОЛОС» (свой текст, до 90 знаков, становится материей в общей
  песочнице: ветер / гравитация / встряска).
- **Технологии:** Canvas 2D + собственный физический движок (импульсный солвер AABB-глифов,
  верлет-сетки, сон-состояния, субшаги), кэш глиф-атлас через measureText и offscreen-canvas.
  Швейцарская бруталистика: бумага #f4f1ea, чернила #17140f, сигнальный красный #d43d1f.
- **Уникальная механика:** редактируемый текст, который живёт в том же физическом мире,
  что и манифест; все размеры тел — из реальных метрик шрифта.
- **Критерий успеха:** 60 fps при 300–800 глифах, покой без дрожи (sleep), разрыв ткани
  читается, ввод своего текста работает, полная стилистика без шаблонности.

## ЭКСП. 05 — «ОРГАНИЗМ» (slug: organism)
- **Измерение веба:** интерфейс, поведение которого определяется действиями пользователей;
  веб как коллективное существо.
- **Концепция:** одно цифровое существо живёт на сервере, и каждый посетитель его кормит.
  Движения курсора и присутствие наполняют личный запас энергии; энергию можно потратить:
  40 — привить ветвь (клик по телу выбирает место прививки), 10 — послать пульс-волну.
  Все прививки пишутся в БД; организм растёт из списка мутаций детерминированно
  (seeded RNG), поколения сменяются каждые 12 прививок, интерфейс «взрослеет» вместе
  с поколением. Лента событий: «гость №N привил ветвь N минут назад».
- **Технологии:** Canvas 2D рекурсивный люминесцентный полип из мутаций, API
  GET/POST /api/organism (Prisma/SQLite, инмемори rate-limit, оптимистичный апдейт,
  поллинг 5 c, офлайн-режим с локальным рендером последнего состояния).
- **Уникальная механика:** энергия как валюта внимания + детерминированный рост из
  общей истории; существо одно на всех посетителей.
- **Критерий успеха:** перезагрузка страницы сохраняет существо, две вкладки видят
  взаимные изменения, экономика энергии режет спам, деградация при офлайне аккуратна.

## Лаборатория (lab) — Этап V
10+ микро-демо с живыми параметрами: flow field, curl noise, SDF-площадка (raymarch с
тумблерами), дизеринг/палитры, feedback-трейлы, текст→частицы, halftone, L-система 2D,
verlet-канат (слайдер итераций), осциллограф Web Audio. Переиспользуемые модули:
src/lib/lab/ (gl.ts — контекст/программа/квад/resize; math.ts — noise/rng/easing;
useDemoLoop.ts — RAF-lifecycle; palette.ts).

## Отчёт (report) — Этап VIII
Интерактивная витрина: карточки 5 экспериментов, сравнительная матрица + радары по критериям
(визуальная новизна / техническая глубина / характер интерактива / нагрузка на GPU / статус),
исследовательская часть (выводы из research/), находки и ограничения, живая статистика визитов
из /api/telemetry, доступ в лабораторию.

## Общие решения
- Единая точка входа `/`, hash-роутинг, ленивые загрузки (ssr:false), телеметрия визитов.
- Палитры пяти экспериментов не пересекаются и не используют синий/индиго как доминанту:
  01 угольно-тлеющий янтарь; 02 слива-маджента-кислотный; 03 кость-терракота (свет);
  04 бумага-чернила-красный (свет); 05 бездонно-зелёный биолюминесцент.
- Шрифты: Onest (гротеск), Cormorant (антиква), JetBrains Mono (данные), Unbounded (дисплей).
- «Лабораторность» как эстетика проекта — подтверждена трендом (Awwwards 2025–2026,
  Chladni · A Geometry of Sound и микрокоманды) — см. research/references.md.
